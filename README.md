# Fitness-AI 🏋️

AI-powered Fitness Application with personalized Workout Plans, Diet Plans, Progress Tracking, and intelligent AI coaching.

## 🚀 Quick Start

**Easiest way to run:**
1. Double-click **`START-ALL.bat`**
2. Open http://localhost:5173 in your browser

📖 **Detailed setup guide**: See [SETUP.md](SETUP.md)
⚡ **Quick reference**: See [QUICK-START.md](QUICK-START.md)

## ✨ Features

- 🤖 **AI-Powered Plans** - Personalized 7-day workout and diet plans using Google Gemini
- 💬 **Intelligent Chat Coach** - Context-aware AI that knows your goals and progress
- 📊 **Progress Tracking** - Weight logs, task completion, streaks, and performance metrics
- ✅ **Task Management** - Automated task creation from plans with push notifications
- 📄 **Document Intelligence** - Upload PDFs for personalized advice
- 🎯 **Goal Setting** - Track fitness goals with deadline-based plans
- 🔔 **Smart Notifications** - Push notifications 15 minutes before tasks
- 📈 **Analytics Dashboard** - Visualize your fitness journey

## 🛠️ Tech Stack

**Backend:**
- FastAPI (Python)
- MongoDB Atlas
- LangChain + Google Gemini AI
- ChromaDB (Vector Store)
- AssemblyAI (Speech-to-Text)
- ElevenLabs (Text-to-Speech)

**Frontend:**
- React 18 + TypeScript
- Vite
- TailwindCSS
- Framer Motion
- Recharts

## 📋 Requirements

- Python 3.10+
- Node.js 16+
- MongoDB Atlas account

### Fitness AI Frontend (React + Vite + Tailwind + TypeScript)

- Install: `npm install`
- Dev: `npm run dev`
- Build: `npm run build`

Config:
- Set `VITE_API_BASE_URL` (defaults to `http://localhost:8000`) in your environment.
- Windows: edit `frontend\run_frontend.bat` or set user env var.
- Unix: export before running: `export VITE_API_BASE_URL=http://localhost:8000`.

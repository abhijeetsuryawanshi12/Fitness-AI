🔧 TROUBLESHOOTING
--------------------------------------------------------------------------------

Problem: "Address already in use" (Port 8000 or 5173 busy)
Solution:
  netstat -ano | findstr :8000
  taskkill /PID <number> /F

Problem: Backend won't start / Import errors
Solution:
  Make sure virtual environment is activated (you should see "(venv)")
  Reinstall dependencies: pip install -r requirements.txt

Problem: Frontend won't start / Module errors
Solution:
  Delete node_modules: rmdir /s /q node_modules
  Reinstall: npm install

Problem: Blank page or errors in browser
Solution:
  1. Check backend is running (visit http://127.0.0.1:8000/docs)
  2. Open browser DevTools (F12) and check Console tab
  3. Clear browser cache (Ctrl+Shift+Delete)

Problem: MongoDB connection failed
Solution:
  - Check internet connection
  - Verify app/.env has correct MONGODB_URI
  - MongoDB Atlas cluster must be running
